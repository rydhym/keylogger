# ClearTrail engineering guidelines v2
Read PROGRESS.md, decision.md, tech.md, flow.md and applicable specifications before work. Archived keyboard specifications are historical.
Implement small verifiable increments. Prefer platform capabilities; review dependencies. Keep crypto/file/network/usage processing off the Android UI thread. Bound lookbacks, queues, memory, pagination, request sizes and retention.
Never log bodies, pairing bundles, keys or tokens. Test failure recovery and privacy boundaries. Keep synthetic evidence separate from device results. Preserve user changes and synchronize docs. Update PROGRESS.md last. Do not claim builds, device compatibility or production readiness without evidence.
